# Terokai Kulai - Laman Web Pelancongan Kulai, Johor

Laman web responsif dan moden yang memaparkan destinasi pelancongan menarik di Kulai, Johor. 

## 🚀 Panduan Panduan Deploy di GitHub Pages

1. **Upload Fail**: Muat naik fail `index.html` dan `README.md` ke dalam repository GitHub anda.
2. **Aktifkan GitHub Pages**:
   - Pergi ke **Settings** > **Pages**.
   - Pilih Branch `main` (atau `master`) dan folder `/ (root)`.
   - Klik **Save**.
3. **Selesai!** Laman web anda sedia diakses.

## 🛠️ Teknologi Yang Digunakan
- **HTML5**
- **Tailwind CSS** (via CDN)
- **FontAwesome Icons**
- **JavaScript (Vanilla)**
